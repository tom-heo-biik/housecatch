# README.md


## Claude(Opus 5.5), 하우스캐치 블로그, 2026. 11. 5., 200, Biik
이 레포는 하우스캐치의 네이버 블로그 글을 Claude Code로 쓰는 도구입니다. 비익이 만든 블로그 자동화 엔진 두루미를 하우스캐치에 맞춰 담았습니다. Claude Code에서 /housecatch를 부르면 지난 글과 겹치지 않는 주제 다섯 개를 새로 정하고, 다섯 편을 한꺼번에 써서 네이버 스마트에디터에 붙여 넣을 수 있는 HTML 파일로 저장합니다. 글 한 묶음에는 20분 안팎이 걸립니다. 주제를 고르고 글을 쓰는 데 드는 시간을 줄이려고 만들었습니다.


## Claude(Opus 5.5), 설치, 2026. 11. 5., 200, Biik
Claude Code에 `powershell -c "irm https://raw.githubusercontent.com/tom-heo-biik/housecatch/main/install.ps1|iex"`를 실행해 달라면 설치됩니다. 이 레포를 사용자 폴더의 housecatch에 받고, 파이썬과 /housecatch 스킬, 바탕 화면 바로가기 둘을 만듭니다. 끝나면 Claude Code를 다시 열어 주세요.


## Claude(Opus 5.5), 쓰기, 2026. 11. 5., 200, Biik
바탕 화면의 하우스캐치 블로그 쓰기를 두 번 누르거나, 어느 폴더에서든 Claude Code를 열고 /housecatch를 입력하면 됩니다. 처음 한 번은 Claude 로그인과 폴더 확인 창이 뜹니다. 다 쓴 글은 바탕 화면 하우스캐치 블로그 폴더의 발행 전 폴더에 쌓이고, 다 올린 글은 발행 완료 폴더로 옮겨 두시면 됩니다. 네이버가 기계적인 발행으로 보지 않도록 하루 한 편씩, 시각을 조금씩 달리해 올려 주세요. 글 속 사진 자리에는 직접 찍은 현장 사진들을 넣어 주세요.


## Claude(Opus 5.5), 업데이트, 2026. 11. 5., 200, Biik
업데이트는 따로 하지 않아도 됩니다. /housecatch를 부를 때마다 이 레포에 새 판이 올라왔는지 먼저 확인하고, 있으면 받아서 엔진과 스킬을 바꾼 뒤 글을 씁니다. 그동안 쓴 글이 든 블로그 폴더, 주제 목록과 주제 기록, 실행 기록, 함께 받은 파이썬은 업데이트가 건드리지 않습니다. 인터넷이 끊겨 확인하지 못하면 지금 판 그대로 씁니다. 그래서 비익이 고친 내용은 하우스캐치 쪽에서 아무것도 하지 않아도 다음 글쓰기부터 바로 반영됩니다. 확인에는 몇 초면 됩니다.


## Claude(Opus 5.5), 관리, 2026. 11. 5., 200, Biik
durumi 폴더는 비익 모노레포의 두루미에서 내보낸 사본이라 여기서 고치지 않습니다. 고칠 일이 있으면 모노레포에서 고친 뒤 durumi.py export 명령으로 이 폴더를 다시 채우고 커밋합니다. 마크다운 훅도 모노레포의 같은 파일을 복사해 둔 것입니다. main에 올린 내용은 하우스캐치 PC에 다음 글쓰기 때 곧바로 깔리니, 모노레포에서 시험을 마친 것만 올려 주세요. 주제 목록에서 이미 쓴 주제는 같은 주제가 다시 나가지 않게 내보낼 때 승인을 꺼 둡니다.
